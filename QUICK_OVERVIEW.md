# FreeShow - Quick Overview

## What is FreeShow?

FreeShow is a **free, open-source presentation software** designed to display lyrics, scripture, and multimedia content on large screens. Think of it as an alternative to expensive presentation software like ProPresenter or MediaShout, but completely free.

## Who uses it?

- **Churches** - for displaying song lyrics and scripture during services
- **Event venues** - for conferences, concerts, and presentations  
- **Broadcasters** - with professional NDI integration for live streaming
- **Educators** - for classroom presentations

## Key Capabilities

### 📺 Presentation Features
- Display song lyrics, scripture, and text slides
- Support for videos, images, and audio
- Multiple output displays (audience + stage displays)
- Real-time remote control via web interface

### 🎥 Professional Features  
- NDI integration for broadcast workflows
- Live camera switching and recording
- Advanced effects and transitions
- Multi-screen setups with different content per screen

### 🔧 Technical Features
- Cross-platform (Windows, Mac, Linux)
- Built with Electron + Svelte + TypeScript
- Cloud integration (Google Drive)
- Import PowerPoint, PDF, and other formats

## Why was it created?

The creator found existing presentation software was either:
- **Too expensive** for small churches and organizations
- **Too complex** for average users

FreeShow aims to be both **free** and **easy to use** while still providing professional-grade features.

## How is it funded?

- Completely free to use
- Supported by donations from users
- Maintained by ChurchApps organization
- Open source with community contributions

## Getting Started

1. Download from GitHub releases
2. Install and run
3. Create presentations with built-in templates
4. Display on your screen/projector
5. Control remotely via web interface

## Technical Architecture

- **Frontend**: Svelte-based user interface
- **Backend**: Electron for desktop app + Node.js servers
- **Database**: SQLite for local storage
- **Networking**: Socket.io for real-time features
